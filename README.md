# 万象熔炉 · Myriad Forge

一款向《Little Alchemy》与《Doodle God》致敬的中文要素合成游戏。界面像一座漂浮在深空里的炼金观测台：黄铜星盘、氧化铜绿、炉火与羊皮纸。所有要素图案都由项目内的 24 × 24 像素绘制代码生成，没有使用任何外部美术素材。

主炉之外还有一个“炉外总目录”：8 页试炼、3 则多幕任务，以及一座收藏真品与赝品的失物招领博物馆。

> 从火、水、土、风开始，合成万物。

## 运行

需要 Node.js 20.19+（推荐 22+）。

```bash
npm install
npm run dev
```

打开 Vite 打印的本地地址。生产构建与预览：

```bash
npm run build
npm run preview
```

数据、章节与完整试玩逻辑校验：

```bash
npm run validate
```

## 玩法

- 从**火、水、土、风**四种源初要素开始，两两投入熔炉。
- **389 个原创要素**，分为 12 种类型：源初、天象、矿物、生灵、植物、动物、人间、造物、科技、秘法、星海、哲理。
- **388 条配方**，部分要素拥有多条合成路径。
- 每个要素都有独立的像素图案和一段原创描述。
- 图鉴搜索、类型筛选、未解轮廓、要素档案、已知配方与用途统计。
- 图鉴会给已发现要素标出材料用途：`闲` 表示当前没有已发现的搭档能造出新要素，`尽` 表示会用到它的配方结果都已发现。要素档案会显示当前可合成的新结果数与尚未发现的结果数。
- 选中一样要素后，图鉴会给试过的搭档盖角标：`已` 表示熔出过结果，`空` 表示试过但没有结果。悬停卡片能看到产物。两类配对都会写入存档；旧存档只补记已发现图鉴里的成功配对。
- 图鉴标记可直接当筛选器：`全部`、`闲`、`尽` 随时可点；选中要素后还会出现 `已`、`空`。标记可以多选，结果取并集。点「反选」切换为排除模式，反选可以先开，再选要排除的标记。筛选会和类型、搜索一起生效。
- 七章「创世手记」，共 32 个章节目标，带章节引子、完成旁白、灵光奖励与源初馈赠。
- 每个手记目标会提示当前状态：`现在可合` 表示已有两种材料能直接合出它，`缺材料` 表示还没有能用的组合，完成后显示 `已写下`。「翻阅全部手记」里也会同步显示。
- 每个要素都有等级：源初与馈赠为 Lv0，合成品取两种材料中较高的等级 +1。图鉴卡片右下角、要素档案和发现卡都会显示 Lv。
- 顶栏「谱系」打开全屏要素树：全部要素按 Lv0–Lv14 分层，宽等级拆成 2–3 行；已发现的用实心卡片，未发现的只留剪影；只给已发现且材料齐全的配方画来源线。点已发现要素会高亮它的来源、产物和连线，其余变暗；支持滚轮缩放、拖动画布、跳到等级和适应屏幕。
- 六种终局要素，最高等级为 **Lv7–Lv11**：
  - 生命之树（Lv10）
  - 时间之河（Lv7）
  - 星辰王冠（Lv7）
  - 世界之核（Lv8）
  - 神谕之心（Lv10）
  - 万象归一（Lv11，需先合成前两个终局要素）
- 灵光按钮在要素库标题右侧：花 1 点优先凑当前手记目标，其次是等级最低的新要素；结果等级并列时，选材料等级和最低的组合。炉里只放一个要素时会先为它找搭档。快捷键 `R`，页面会滚到炉边。
- 连续失败会积攒灵光；每发现 10 个要素也会获得灵光。
- 发现卡、章节完成卡、终局仪式与结局演出。
- 本地自动存档、熔炼统计、成功率、重置进度。
- Web Audio 实时合成音效（默认关闭）。
- 桌面端优先布局，按需求不做移动端适配。

## 炉外总目录

主炉之外的内容分为四族：**谜题 / 任务 / 燃尽 / 遗物**。入口是主界面顶栏的「试炼」。炉外总目录不继承主图鉴，也不改变主游戏进度。八页旧挑战使用 50 条独立配方，完成状态与最佳步数/次数保存在 `myriad-forge.challenges.v1`；任务与遗物各有独立存档。

### 总目录结构

| 族 | 数量 | 规则 | 存档键 |
| --- | --- | --- | --- |
| 谜题 | 4 则 | 无步数限制、无失败、3 条提示、Par 星级 | `myriad-forge.challenges.v1` |
| 任务 | 3 则 | 每则 3 幕、1 次不可撤销选择、4 个结局、2 个可选目标；无余烬、无步数上限、无失败 | `myriad-forge.quests.v1` |
| 燃尽 | 4 则 | 有限余烬，成功与失败都扣 | `myriad-forge.challenges.v1` |
| 遗物 | 1 座馆 | 26 块碎片、8 件真品、24 件赝品；三槽鉴定、顺序无关、无失败 | `myriad-forge.artifacts.v1` |

### 谜题：无步数限制

四则小物件谜题，起始要素**全部来自主图鉴之外**，只能使用本页的配方。错误组合不会失败，也没有余烬；每则固定 5 步 Par、3 条提示，并至少包含一条不影响目标的诱饵配方。完成时按实际步数给出 1–3 星，最佳记录会覆盖。

| 谜题 | 最终要素 | 挑战专属起始要素 | 提示 | Par |
| --- | --- | --- | --- | --- |
| 把月亮装进口袋 | 口袋月亮（限定） | 井水、夜布、缝光针、旧蜡、屋檐 | 3 条 | 5 步 |
| 给影子补一双鞋 | 影子的鞋（限定） | 没脚的影子、旧皮、蜂蜡、歪尺、静风 | 3 条 | 5 步 |
| 让雨停下来 | 停雨钟（限定） | 腌云盐、停摆钟、漏雨屋顶、旧火、鱼鳞瓦 | 3 条 | 5 步 |
| 把一句话寄出去 | 漂流信（限定） | 咸墨水、纸鸟、无风带、空瓶、哑火 | 3 条 | 5 步 |

### 燃尽：有限余烬

四则旧故事保留原来的硬约束：每则从一组固定起始要素开始，只能使用本页配方，并且只有有限次熔炼。成功与失败都会消耗余烬。

| 试炼 | 最终要素 | 来源 | 起始要素 | 余烬 | 最少熔炼 |
| --- | --- | --- | --- | --- | --- |
| 余烬的第一口气 | 生命 | 主线要素 | 6 种 | 8 次 | 5 次 |
| 给余烬一双翅膀 | 凤凰 | 主线要素 | 6 种 | 12 次 | 9 次 |
| 守夜人的不灭灯 | 不灭灯 | 试炼限定 | 6 种 | 7 次 | 5 次 |
| 钟表匠错过的下午 | 时间之河 | 主线终局要素 | 8 种 | 10 次 | 7 次 |

挑战限定要素共 48 个，其中 20 个谜题起始要素全部不在主图鉴里。每则挑战有三段叙事：进入前的故事卡、熔炼过程中解锁的故事节拍，以及完成时的结局文本；燃尽失败时另有失败文本。新要素都有自己的像素图、描述与故事节拍。

### 任务：三幕、选择与四个结局

三则任务分别围绕“人 / 时间 / 空间”做选择。每则使用 6 个任务专属起始要素，共 69 个任务限定要素、48 条任务配方。每一幕有自己的目标；第二幕末尾会出现一次不可撤销的三选一，选项会解锁不同的第三幕要素，并决定普通结局。真结局还需要在最终造物之前完成两个可选目标。

| 任务 | 选择轴 | 三幕 | 结局 | 真结局 |
| --- | --- | --- | --- | --- |
| 最后一班渡船 | 谁上船 | 把河照亮 / 谁上船 / 彼岸 | 医生的夜诊、孩子的春天、河的上游、第二条河 | 无影女人 + 船夫的名字 + 三个故事 |
| 给熄灭的星补一次日落 | 投影哪一天 | 聚光 / 投影哪一天 / 最后一次日落 | 记忆里的日落、种下的星、此刻的日落、真正的日落 | 现在 + 失踪的观测记录 + 校准轨道 |
| 不营业的旅馆 | 打开哪扇门 | 叫醒前台 / 打开哪扇门 / 最后一次退房 | 101 的客人、零号房、十三号房、旅馆的名字 | 13 号房 + 旅馆的名字 + 读完登记簿 |

- 没有余烬，没有步数上限，错误组合不会失败；卡住时每一幕有 3 条提示。
- 中途离开会保留“当前幕开头”的检查点；已见结局、可选目标与最佳步数永久保存。
- 任务卡显示已见结局数；结算卡显示本次步数、可选目标完成度与 `已见结局 n / 4`。
- 结局不会因为重走而丢失；真结局与普通结局分别记录。

### 遗物：失物招领博物馆与误会厅

博物馆独立于主图鉴，固定 26 块挑战专属碎片。每次选三块放上鉴定台，顺序无关，碎片不消耗：

- 命中 **8 件真品**之一：收入真品厅，档案归位。
- 命中 **24 件赝品**之一：收入误会厅。赝品不是失败，是馆方认真登记的展品。
- 两者都不是：馆长老白给一句吐槽，不生成展品，也不失败；连续 3 次未命中会主动给提示。

26 个碎片都有 tags、第一人称证词与独立像素图。真品厅每件失物有 3 条证词；误会厅的 24 件赝品按 8「差一点」/ 8「完全误会」/ 8「馆方放弃」分三档，每件都有展签、馆长批注、观众留言和一条提示。集齐 8 真品 + 24 赝品后，触发最终展品「馆长的辞职信（真品）」。

### 收藏总览：进度、徽章、结局图鉴

总目录里的「打开收藏总览」会进入独立的总览页：

- **总进度**：试炼 8 页 + 任务结局 12 个 + 馆藏 32 件，共 52 个单位；显示四族分项进度和总百分比。
- **14 枚徽章**：第一簇炉外火、第一声再见、第一件馆藏、四页谜题、四盏余烬、三次抵达、十二种告别、三次真结局、六个可选、四次校准、真品厅、误会万岁、辞职信、炉外全书。未获得的徽章也会显示当前进度。
- **任务结局图鉴**：12 个结局按任务分组。未抵达的结局只显示空位和条件方向；已抵达的结局保留标题与尾声。
- **八页试炼记录**：显示最佳步数 / 次数；谜题按最佳步数显示 Par 星级。
- **馆藏总览**：真品厅 8 格 + 误会厅 24 格，未发现的展品保留剪影；集齐后显示「馆长的辞职信」。
- 总览里的任务、试炼与博物馆都可以直接点进去继续；所有进度仍使用原有的三套独立存档。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点选图鉴卡片 | 将一个要素放入熔炉（最多两个） |
| 点熔炉槽位的 × | 取出该要素 |
| 按「熔炼」或 `Enter` | 组合两个要素 |
| 点要素库标题旁的「灵光」，或按 `R` | 优先凑当前手记目标；已选一个要素时先为它找搭档，然后自动熔炼 |
| 点顶栏「谱系」 | 打开全屏要素树；在树里按 `Esc` 返回主炉 |
| 点树里的已发现要素 | 高亮它的来源、产物和连线；再点一次或点空白取消 |
| `/` | 聚焦要素搜索 |
| `M` | 开关声音 |
| `Esc` | 关闭面板 / 清空熔炉 |
| 悬停卡片后点左上角 `i` | 打开要素档案 |
| 顶栏「试炼」 | 进入独立的炉外试炼；试炼中可随时回到主炉或试炼目录 |

## 设计方向

- **主题**：深空炼金观测台。黄铜星盘是主要视觉元素，其余界面保持克制。
- **色彩**：`#071215` 虚空深青、`#0d1f26` 仪表底、`#e9d7b1` 羊皮纸文字、`#d5a05b` 黄铜、`#6cb8a3` 氧化铜绿、`#df6b43` 炉火橙。
- **字体**：自托管方舟像素字体（标题与界面）+ 系统宋体（描述与叙事），让仪器读数和手抄本叙事形成对照。
- **字号**：界面最小字号 11px，正文 12–16px；徽章、槽位和状态角标的行高单独校正，避免放大后裁切。
- **布局**：左侧环形星盘熔炉，右侧章节手记，下方整幅要素标本柜。
- **动效**：开场一次完整的星盘苏醒仪式；此后动效只回应玩家动作。`prefers-reduced-motion` 下静帧呈现。
- **像素画**：24 × 24 逻辑像素，统一描边、三阶明暗和少量抖动；要素的调色板与细节由要素 ID 与图形名称确定性生成。

## 自检与验收

`npm run validate` 会检查：

- 要素数量 > 300、ID 与名称唯一、每个要素都有足够长度的描述和已绘制的像素图形。
- 所有配方引用有效，没有自我合成或重复配方对。
- 所有要素都能从源初要素抵达。
- 至少 5 个终局要素等级 ≥ 6。
- 每个章节的目标在对应解锁阶段可抵达，终章包含至少 5 个终局要素。
- 源初与馈赠要素为 Lv0，合成品等级等于较高材料等级 +1，并与独立校验的等级一致。
- 谱系树：包含全部 389 个要素，节点层级与等级一致；宽等级拆成 2–3 行，来源线只画给已发现且材料齐全的配方，且从低等级指向高等级。
- 自动从四种源初要素开始模拟完整通关：必须抵达全部 389 个要素、完成全部 7 章并触发结局。
- 灵光选对：优先当前手记目标，其次等级最低，再比较材料等级和；已选一个要素时会保留它并优先找搭档；全图鉴后返回空。

- 谜题必须没有余烬上限，起始要素和配方全部来自主线之外，至少有 3 条提示和 1 条诱饵配方；错误组合不得导致失败。
- 燃尽试炼的最少熔炼次数不得超过余烬上限；并用实际试炼引擎跑完整路线，确保完成判定可用。
- 至少包含一个主线目标和一个试炼限定目标。
- 三则任务：每则 3 幕、4 个结局、2 个可选目标、6 个专属起始要素；起始要素与全部配方不引用主线要素。
- 任务要素都有描述、像素图和故事节拍；每幕目标可达；每个选项都有对应普通结局。
- 用实际任务引擎分别跑通 12 个普通结局和 3 个真结局；真结局必须依赖至少两个可选目标，普通结局路线不得依赖可选目标。
- 任务无效组合不会失败；任务没有步数或余烬上限。
- 遗物：26 个碎片都有 tags、证词、描述和像素图；8 件真品、24 件赝品（8 / 8 / 8）各有 3 个材料。
- 32 条有效三材料组合互不重叠，所有碎片至少被使用一次；三槽引擎能鉴定全部真品与赝品。
- 未命中组合不失败；连续 3 次未命中会触发馆长提示；赝品集齐后提示转向真品厅；8 + 24 触发收尾条件。
