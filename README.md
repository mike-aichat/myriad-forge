# 万象熔炉 · Myriad Forge

一款向《Little Alchemy》与《Doodle God》致敬的中文要素合成游戏。界面像一座漂浮在深空里的炼金观测台：黄铜星盘、氧化铜绿、炉火与羊皮纸。所有要素图案都由项目内的 24 × 24 像素绘制代码生成，没有使用任何外部美术素材。

> 在虚无里点燃第一簇火，然后看看万物愿不愿意跟你走。

## 运行

需要 Node.js 20.19+（推荐 22+）。

```bash
npm install
npm run dev
```

打开 Vite 打印的本地地址。生产构建与预览：

```bash
npm run build
npm run preview
```

数据、章节与完整试玩逻辑校验：

```bash
npm run validate
```

## 已经完成的玩法

- 从**火、水、土、风**四种源初要素开始，两两投入熔炉。
- **389 个原创要素**，分为 12 种类型：源初、天象、矿物、生灵、植物、动物、人间、造物、科技、秘法、星海、哲理。
- **388 条配方**，部分要素拥有多条合成路径。
- 每个要素都有独立的像素图案和一段原创描述。
- 图鉴搜索、类型筛选、未解轮廓、要素档案、已知配方与用途统计。
- 七章「创世手记」，共 32 个章节目标，带章节引子、完成旁白、灵光奖励与源初馈赠。
- 六种终局要素，最短合成链深度为 **7–11 层**：
  - 生命之树（10 层）
  - 时间之河（7 层）
  - 星辰王冠（7 层）
  - 世界之核（8 层）
  - 神谕之心（10 层）
  - 万象归一（11 层，需先合成前两个终局要素）
- 灵光提示系统：优先指向当前章节目标，只使用已经发现的要素。
- 连续失败会积攒灵光；每发现 10 个要素也会获得灵光。
- 发现卡、章节完成卡、终局仪式与结局演出。
- 本地自动存档、熔炼统计、成功率、重置进度。
- Web Audio 实时合成音效（默认关闭）。
- 桌面端优先布局，按需求不做移动端适配。

## 炉外试炼（独立挑战模式）

主炉之外有八页短篇：四则**谜题**与四则**燃尽**。入口是主界面顶栏的「试炼」，它会切换到独立的挑战界面，不继承主图鉴，也不会改变主游戏进度。八页挑战使用 50 条独立配方，完成状态与最佳步数/次数独立保存在 `myriad-forge.challenges.v1`。

### 谜题：无步数限制

四则小物件谜题，起始要素**全部来自主图鉴之外**，只能使用本页的配方。错误组合不会失败，也没有余烬；每则固定 5 步 Par、3 条提示，并至少包含一条不影响目标的诱饵配方。完成时按实际步数给出 1–3 星，最佳记录会覆盖。

| 谜题 | 最终要素 | 挑战专属起始要素 | 提示 | Par |
| --- | --- | --- | --- | --- |
| 把月亮装进口袋 | 口袋月亮（限定） | 井水、夜布、缝光针、旧蜡、屋檐 | 3 条 | 5 步 |
| 给影子补一双鞋 | 影子的鞋（限定） | 没脚的影子、旧皮、蜂蜡、歪尺、静风 | 3 条 | 5 步 |
| 让雨停下来 | 停雨钟（限定） | 腌云盐、停摆钟、漏雨屋顶、旧火、鱼鳞瓦 | 3 条 | 5 步 |
| 把一句话寄出去 | 漂流信（限定） | 咸墨水、纸鸟、无风带、空瓶、哑火 | 3 条 | 5 步 |

### 燃尽：有限余烬

四则旧故事保留原来的硬约束：每则从一组固定起始要素开始，只能使用本页配方，并且只有有限次熔炼。成功与失败都会消耗余烬。

| 试炼 | 最终要素 | 来源 | 起始要素 | 余烬 | 最少熔炼 |
| --- | --- | --- | --- | --- | --- |
| 余烬的第一口气 | 生命 | 主线要素 | 6 种 | 8 次 | 5 次 |
| 给余烬一双翅膀 | 凤凰 | 主线要素 | 6 种 | 12 次 | 9 次 |
| 守夜人的不灭灯 | 不灭灯 | 试炼限定 | 6 种 | 7 次 | 5 次 |
| 钟表匠错过的下午 | 时间之河 | 主线终局要素 | 8 种 | 10 次 | 7 次 |

挑战限定要素共 48 个，其中 20 个谜题起始要素全部不在主图鉴里。每则挑战仍有三层叙事：进入前的故事卡、熔炼过程中逐行解锁的故事节拍、以及完成时的结局文本；燃尽失败时另有失败文本。所有新要素都有自己的像素图、描述与故事节拍。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点选图鉴卡片 | 将一个要素放入熔炉（最多两个） |
| 点熔炉槽位的 × | 取出该要素 |
| 按「熔炼」或 `Enter` | 组合两个要素 |
| `/` | 聚焦要素搜索 |
| `M` | 开关声音 |
| `Esc` | 关闭面板 / 清空熔炉 |
| 悬停卡片后点左上角 `i` | 打开要素档案 |
| 顶栏「试炼」 | 进入独立的炉外试炼；试炼中可随时回到主炉或试炼目录 |

## 设计方向

- **主题**：深空炼金观测台，而不是中式仙侠。黄铜星盘是唯一的主角，其余界面保持克制。
- **色彩**：`#071215` 虚空深青、`#0d1f26` 仪表底、`#e9d7b1` 羊皮纸文字、`#d5a05b` 黄铜、`#6cb8a3` 氧化铜绿、`#df6b43` 炉火橙。
- **字体**：自托管方舟像素字体（标题与界面）+ 系统宋体（描述与叙事），让仪器读数和手抄本叙事形成对照。
- **布局**：左侧环形星盘熔炉，右侧章节手记，下方整幅要素标本柜。
- **动效**：开场一次完整的星盘苏醒仪式；此后动效只回应玩家动作。`prefers-reduced-motion` 下静帧呈现。
- **像素画**：24 × 24 逻辑像素，统一描边、三阶明暗和少量抖动；要素的调色板与细节由要素 ID 与图形名称确定性生成。

## 自检与验收

`npm run validate` 会检查：

- 要素数量 > 300、ID 与名称唯一、每个要素都有足够长度的描述和已绘制的像素图形。
- 所有配方引用有效，没有自我合成或重复配方对。
- 所有要素都能从源初要素抵达。
- 至少 5 个终局要素最短深度 ≥ 6。
- 每个章节的目标在对应解锁阶段可抵达，终章包含至少 5 个终局要素。
- 自动从四种源初要素开始模拟完整通关：必须抵达全部 389 个要素、完成全部 7 章并触发结局。
- 失败熔炼与灵光提示的烟雾测试。
- 八则挑战：谜题/燃尽分族、起始要素、目标、故事字段、限定配方、故事节拍、像素图形与最少步数。
- 谜题必须没有余烬上限，起始要素和配方全部来自主线之外，至少有 3 条提示和 1 条诱饵配方；错误组合不得导致失败。
- 燃尽试炼的最少熔炼次数不得超过余烬上限；并用实际试炼引擎跑完整路线，确保完成判定可用。
- 至少包含一个主线目标和一个试炼限定目标。
