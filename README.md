# 万象熔炉 · Myriad Forge

一款向《Little Alchemy》与《Doodle God》致敬的要素合成游戏。界面为中文，气质是一个漂浮在深空中的炼金观测台：黄铜星盘、氧化铜绿、炉火与羊皮纸。全部要素图案均由项目内的像素绘制代码生成，没有使用外部美术素材。

> 在虚无里点燃第一簇火，然后看看万物愿不愿意跟你走。

## 运行

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

数据自检（要素数量、配方完整性、可达性、终局深度）：

```bash
npm run validate
```

## 玩法

- 从**火、水、土、风**四种源初要素开始。
- 在熔炉中选择两种要素进行熔炼，发现新要素；部分要素有多种合成路径。
- 每次发现都会永久收录进要素库，并附上一段手写体描述。
- 完成「创世手记」的章节任务，解锁新的源初馈赠、灵光与结局文本。
- 卡住时使用「灵光」获取一条只涉及已发现要素的提示；失败也会偶尔擦出灵感。
- 进度自动保存在浏览器本地，可随时继续。

## 规划中的完整功能

### 核心系统

- [ ] 340+ 个原创要素，分为源初、天象、矿物、植物、动物、人类、造物、科技、魔法、宇宙、哲理等类型
- [ ] 每个要素拥有独立的像素图案、类型色彩与一段有趣描述
- [ ] 两两熔炼、成功 / 失败反馈、重复合成提示
- [ ] 至少 5 个终局要素，最短合成链深度不少于 6 层
- [ ] 部分要素支持多条合成路径，降低卡关挫败
- [ ] 要素图鉴：搜索、类型筛选、未发现占位、详情面板、已知配方
- [ ] 灵光提示系统：优先指向当前章节目标，消耗灵光并显示一对可行要素
- [ ] 本地存档、统计（熔炼次数、成功率、最快发现）、重置进度

### 叙事与挑战

- [ ] 七章「创世手记」，从元素初醒到文明、科技、星空与神话
- [ ] 每章 4–6 个任务、章节引子、完成奖励与幕后旁白
- [ ] 章节解锁源初要素「光」「暗」，并更新世界状态
- [ ] 终章要求合成五个终局要素，并触发结局
- [ ] 结局后可继续自由探索，显示全收集进度与称号

### 表现

- [ ] 纯代码绘制的像素要素图标（24 × 24，统一描边与三阶明暗）
- [ ] 环形星盘熔炉主舞台：实时炉火、烟雾、轨道碎片
- [ ] 深空像素星场背景、黄铜刻度、氧化铜绿与羊皮纸质感
- [ ] 发现卡、章节横幅、终局仪式等编排式动效
- [ ] Web Audio 合成音效：选择、成功、失败、发现、章节完成
- [ ] 键盘可操作、清晰焦点、尊重 `prefers-reduced-motion`
- [ ] 桌面端优先布局（按需求不做移动端适配）

## 设计方向

- **主题**：深空炼金观测台，而非中式仙侠。黄铜星盘是唯一的主角，其余界面保持克制。
- **色彩**：`#081316` 虚空深青、`#0f2028` 仪表底、`#e7d5ae` 羊皮纸文字、`#d5a05b` 黄铜、`#6cb8a3` 氧化铜绿、`#dd6b43` 炉火橙。
- **字体**：自托管方舟像素字体（标题与界面）+ 系统宋体（描述与叙事），让数据界面与手抄本叙事形成对照。
- **布局**：左侧巨大环形熔炉，右侧章节手记，下方整幅要素标本柜。
- **动效**：开场一次完整的星盘苏醒仪式；之后只回应玩家动作，不做满屏漂浮。
